# Sports Hub

A small Next.js + TypeScript starter for football fixtures and match information.

Features:
- Fixtures view
- League listing
- Simple in-memory API routes (fixtures, leagues)
- Tailwind CSS for styling

Getting started

1. Install dependencies

```bash
npm install
# or
# pnpm install
# yarn
```

2. Run the development server

```bash
npm run dev
```

Open http://localhost:3000

What's included and next steps

- pages/ — basic pages: index (fixtures) and leagues
- pages/api — simple API routes returning sample data
- components/ — Header and MatchCard examples
- Tailwind CSS wired up

Possible next improvements:
- Persist data with a database (SQLite / Postgres)
- Add authentication
- Add favorites, push notifications or live-score integration
- Add tests and CI
